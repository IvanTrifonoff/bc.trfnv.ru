# Баллистический калькулятор (PWA)

Офлайн PWA-калькулятор траектории на Vanilla JS. Модель точечной массы с реальными
кривыми сопротивления G1/G7, метрические единицы, справочник патронов и оружия,
прицельная картинка с экспортом в PNG и печатью. Работает без интернета после
первой загрузки, адаптирован для телефона.

## Запуск

### Вариант A: Caddy сам получает сертификат

Порты 80/443 свободны, A-запись домена указывает на VPS:

```bash
echo 'SITE_ADDR=bc.trfnv.ru' > .env
docker compose up -d --build
```

### Вариант B: за уже существующим nginx (как на нашем VPS)

Caddy работает в HTTP-режиме и слушает только localhost:

```bash
cp .env.example .env          # SITE_ADDR=:80, HTTP_BIND=127.0.0.1, HTTP_PORT=6031
docker compose up -d --build
sudo cp deploy/nginx-bc.trfnv.ru.conf /etc/nginx/sites-available/bc.trfnv.ru
sudo ln -sf /etc/nginx/sites-available/bc.trfnv.ru /etc/nginx/sites-enabled/bc.trfnv.ru
sudo certbot certonly --webroot -w /var/www/html -d bc.trfnv.ru --agree-tos -n
sudo nginx -t && sudo systemctl reload nginx
```

## Структура

- `public/` — статический фронтенд (PWA)
- `public/js/ballistics.js` — движок расчёта (G1/G7, RK4, ветер, угол, среда, прямой выстрел, поправки для режима «Охота»)
- `public/js/drag-tables.js` — таблицы Cd(Mach) G1/G7
- `public/js/chart.js` — график траектории на canvas
- `public/js/reticle.js` — прицельная картинка, экспорт PNG, печать
- `public/sw.js` — service worker, кэширует всё необходимое для офлайна
- `public/data/catalog.json` — справочник патронов и винтовок
- `Caddyfile`, `Dockerfile`, `docker-compose.yml` — контейнер с HTTPS

## Офлайн-режим

При первой загрузке онлайн service worker кэширует оболочку приложения и
`catalog.json`. Дальше приложение открывается и считает без интернета. Ваши
параметры и добавленные вручную патроны/винтовки хранятся в `localStorage`.

## Два режима

- **⚙ Настройка / Пристрелка** — полный ввод параметров, таблица, график, прямой
  выстрел и прицельная картинка. Здесь задаются патрон, оружие, дистанция
  пристрелки и сохраняется профиль.
- **🌲 Охота** — рабочий режим: сверху краткая сводка профиля, вводятся только
  температура, давление, ветер и расстояние до цели. Сразу показываются крупные
  поправки по высоте и ветру (мм / мрад / щелчки) и прицельная картинка с точкой
  попадания. Угол прицела берётся зафиксированным при пристрелке (без ветра),
  поэтому поправки корректны при изменившихся условиях и не требуют
  перепристрелки. Вводимые значения и выбранный режим сохраняются.

## Интерфейс

- **Подсказки:** над каждым полем — понятное пояснение, что именно вводить и в каких единицах.
- **Дистанции:** вводятся диапазоном «от / до / шаг». Например 40 / 100 / 10 даст
  40, 50, 60, 70, 80, 90, 100 м.
- **Галочки:**
  - заголовки разделов включают/выключают блоки ввода (например, условия стрельбы
    скрыты по умолчанию, дополнительные G7/клики — тоже);
  - над таблицей галочками выбираются нужные столбцы — остальные не выводятся.
  - состояния галочек сохраняются вместе с параметрами.
- **Тёмная тема:** переключатель в шапке, выбор запоминается в `localStorage`.
- **Телефон:** на ширине ≤640 px поля идут в один столбец, а таблица результатов
  превращается в карточки — горизонтальной прокрутки нет. График и прицельная
  картинка масштабируются по ширине экрана.
- **График траектории** перерисован: градиентная заливка, зона цели, снос по
  правой оси, маркеры ближнего/дальнего нуля, апогея и границы МПВ.
- **Прямой выстрел:** по заданной высоте цели (поле в блоке «Пристрелка»)
  рассчитываются ближний и дальний нули, апогей (превышение над линией прицела)
  и максимальная дистанция прямого выстрела (МПВ) — пуля не выходит за зону
  поражения. Все四项 выводятся карточками и отображаются на графике.
- **Пристрелка:** дистанция пристрелки вынесена в отдельный блок и больше не
  перезаписывается при выборе винтовки из справочника — это ваш параметр.
- **Прицельная картинка:** миллирадианная сетка (мил-точки или перекрестие),
  квадрат цели заданного размера и красная метка точки попадания. Можно выбрать
  дистанцию, скачать PNG (1680×1680) или распечатать — в печать уходит только картинка.
- **Угловые поправки** выводятся именно в миллирадианах (1 мрад ≈ 1 мм на 1 м),
  вместе с количеством щелчков при заданной цене щелчка.

## Проверка на .22LR

Рекомендованный стартовый набор:
- патрон CCI Standard Velocity (2,59 г, BC G1 0,112, 326 м/с)
- винтовка с высотой прицела 25 мм, пристрелка 50 м
- дистанции 10, 25, 50, 75, 100 м

Высота прицела и BC стоит откалибровать по вашему хронографу и реальным
попаданиям — это приближённая модель, а не баллистический радар.

## Модели и источники

- Таблицы сопротивления **G1/G7** (`public/js/drag-tables.js`) взяты из
  [gehtsoft-usa/BallisticCalculator1](https://github.com/gehtsoft-usa/BallisticCalculator1)
  (LGPL-2.1) — это реальные Cd(Mach) эталонных снарядов, а не приближение.
- Идеи для развития почерпнуты из открытых проектов:
  [geladen-ch/ballistic-tools](https://github.com/geladen-ch/ballistic-tools) —
  почти такой же офлайн-PWA, но с калибровкой BC по хронографу, трассировкой ошибок
  пристрелки, вероятностью попадания и 4DOF; [o-murphy/js-ballistics](https://github.com/o-murphy/js-ballistics)
  — WASM-ядро с многослойным ветром, Coriolis и danger space;
  [nikolaygekht/ballistic.calculator.app.avalonia](https://github.com/nikolaygekht/ballistic.calculator.app.avalonia)
  — 3DOF + spin drift, аэродинамический скачок и пользовательские кривые `.drg`.
- BC G7 в справочнике пересчитан из G1 через отношение Cd(G7)/Cd(G1) у дульного
  числа Маха — это оценка; для точной работы задайте G7 вручную по данным производителя.

## Что можно добавить дальше

1. Калибровка BC/скорости по хронографу и по реальным попаданиям (truing).
2. Многослойный ветер по дистанции, кориолис, spin drift (для винтовок покрупнее).
3. Прямой выстрел / danger space и ближняя-дальняя пристрелка.
4. Вероятность попадания и «карточка цели» для полевого использования.
5. Загрузка пользовательской кривой Cd(Mach) из CSV (`.drg`-подобный формат).
6. Сохранение нескольких профилей «патрон + винтовка + пристрелка» в JSON.
